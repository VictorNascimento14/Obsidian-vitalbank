# PR #10 — ui(fontes): carregar Inter e Lato pelo next/font

## 🎯 Contexto

Fundação do [[2026-10-02-plano-da-v1]]. Família tipográfica em [[linguagem-visual]]. Fecha a issue #9.

## 🔧 Mudanças

- `src/app/layout.tsx` — `Inter` e `Lato` de `next/font/google`, cada uma numa variável CSS (`--fonte-inter`, `--fonte-lato`) aplicada no `<html>`.
- `src/app/globals.css` — `--font-sans` e `--font-cartao` no `@theme inline`.

## 🧠 Decisões técnicas

- **Variável CSS em vez de `className` da fonte.** O Tailwind consome a fonte por token (`font-sans`, `font-cartao`), como qualquer outro valor do design system.
- **Lato só com os pesos usados** (400 e 700): cada peso é um arquivo a mais.
- **`@theme inline`** porque o valor é uma `var()` definida em tempo de execução pelo `next/font`.

## ⚠️ Armadilhas e aprendizados

- O build agora baixa as fontes do Google: sem rede, `pnpm build` falha. O CI tem rede; em máquina offline, o cache do `.next` resolve depois do primeiro build.

## 🧪 Como testar

1. Fonte Inter no app; `Inter Fallback` no CSS do build.
